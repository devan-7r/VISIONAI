PROJECT NAME

VisionAI Backend

=====================================================

OBJECTIVE

Build a production-ready backend for the VisionAI Object Detection Web Application.

The backend should integrate seamlessly with a React + Vite frontend.

Tech Stack

Flask

Ultralytics YOLO11 (or latest stable YOLO)

OpenCV

NumPy

Pillow

Flask-CORS

Flask-SocketIO (for live detection)

SQLite (development)
